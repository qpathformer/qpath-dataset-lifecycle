# SPDX License Identification

All scripts in this repository include SPDX license identifiers
to support automated license scanning and artifact traceability.

The identifier used in this repository is:

SPDX-License-Identifier: QPATHFORMER-PLATFORM-1.0

This identifier corresponds to the custom platform license
included in the repository:

QPATHFORMER-PLATFORM-1.0.txt

## Purpose

SPDX headers allow tools and auditors to:

- identify the governing license
- trace licensing across artifacts
- verify compliance automatically

## Scope

SPDX headers apply to:

- Python scripts in `tools/`
- reference implementations
- supporting utilities included in the repository

Documentation files may omit SPDX headers where a
repository-level license declaration applies.
