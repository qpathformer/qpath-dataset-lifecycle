# Execution Toolkit Documentation

This directory contains the **Implementation Guidance Companion and Running the Tools documentation**
for the Governed Dataset Lifecycle Framework.

The companion document demonstrates how repository tooling can be used
to convert inspection artifacts into lifecycle-governed datasets.

Two formats are provided in docs/execution_toolkit/

• Implementation Guidance.md and DOCX (Companion)  
• Running the Tools.md (execution examples)

This guidance is **informative** and does not define governance semantics.

Normative definitions remain in **APOD-TR-007**.
