# Boundary Statement

This repository is the reference implementation layer for the governed dataset lifecycle release.

It provides:
- dataset lifecycle tooling
- schema extensions
- routing and conversion utilities
- example implementation flows

It does not define:
- governance authority
- policy meaning
- certification semantics
- regulatory status

Governance semantics remain defined by the Access-PoD repository.
This implementation may consume or process governed artifacts, but it does not determine governance authority.
